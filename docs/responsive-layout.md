# 电脑、平板与手机适配

更新日期：2026-09-12。

同一套网站会随浏览器可用宽度自动切换布局，无需选择“电脑版”或“手机版”。保留原有品牌配色、13 款产品、工厂图库和业务联系方式。

| 使用场景 | 布局 |
| --- | --- |
| 大屏电脑，1600px 起 | 内容宽度上限 1440px，完整桌面导航，商品五列 |
| 普通电脑，1200–1599px | 商品四列，完整导航；宽度至少 1100px 且高度至少 600px 时询价窗口双栏 |
| 小笔记本／平板横屏，900–1199px | 商品三列；1024px 起完整导航，其余使用折叠菜单 |
| 平板竖屏／手机，380–899px | 商品两列；平板系列入口两列，内容按可用宽度重新排布 |
| 小手机，379px 及以下 | 商品、系列入口和工厂图片改为单列 |
| 手机横屏／较矮窗口 | 缩短首屏与菜单间距，弹窗可滚动；横屏使用横版视频 |

## 交互细节

- 调整窗口到桌面宽度时，已打开的移动菜单自动关闭并释放焦点。
- 视频在横竖屏切换时选择对应画幅，保留用户暂停意图，继续尊重减少动态效果与节流偏好。
- 询价、商品详情和工厂图片弹窗内部滚动，关闭按钮固定在弹窗右上角。
- 工厂大图支持左右按钮、键盘左右键和 Escape 关闭。
- 消息预览使用有高度限制的文本区域；多款数量、OEM 信息、确认后打开 WhatsApp 的流程保持不变。
- 明确设置设备视口与安全区，输入框保留 16px 字号，允许浏览器缩放。

## 验证记录

使用桌面 Chrome 的浏览器视口模拟检查以下 15 种尺寸，不代表已在每种实体设备上测试：

320×568、360×800、390×844、430×932、667×375、844×390、768×1024、820×1180、1024×768、640×400、1280×800、1366×768、1440×900、1920×1080、2560×1440。

全部通过页面横向溢出、菜单断点、商品列数、商品详情、数量修改、消息预览、OEM 字段、弹窗边界与滚动后关闭、工厂图库按钮／键盘切换检查。另验证菜单跨断点关闭和视频旋转后保持暂停。未向外部发送咨询消息。

相关检查：`node scripts/check-inquiries.mjs`、`pnpm exec tsc --noEmit`、`pnpm build`。

可选浏览器检查：安装 Playwright 并使用本机 Chrome，启动网站后执行 `node scripts/check-responsive.mjs`；运行环境也可通过 `PLAYWRIGHT_MODULE_PATH` 指定已安装的 Playwright 模块。检查输出写入忽略的 `output/responsive-qa/`。
