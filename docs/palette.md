# 全站配色与流程排版 · 2026-09-15

当前视觉为象牙白与深墨绿。主体采用明亮象牙白，页脚和顶部提示条采用深墨绿，主按钮、标题强调与选中状态使用品牌绿。浅植物绿仅区分卡片和辅助区块。替换之前的灰褐色底色和文字，不以金色作为主要装饰。

| 用途 | 颜色 |
| --- | --- |
| 页面和联系区底色 | 象牙白 #FFFEF9 |
| 产品卡片底色 | 白色 #FFFFFF |
| 辅助底色 | 浅植物绿 #F4F8EE / #EAF2DF |
| 正文 | 深绿 #18392D |
| 次级正文 | 叶绿 #476254 |
| 主按钮和品牌强调 | #18543D，配象牙白文字 |
| 页脚与顶部提示条 | 深墨绿 #124734 |
| 深色区辅助文字 | 浅绿白 #D4E5CA |

页脚独立设置标志、导航、辅助文字、分隔线、悬停和键盘焦点的颜色，确保深底上的可读性。联系方式保留浅底深字。商品图片改用白色底，避免浅色背景影响图片颜色。产品详情、询盘表单、隐私页与销售后台共用语义变量。

## 流程错位修复

原流程数字使用绝对定位，字体放大后超过旧有文字左边距，造成 01/02/03 与标题重叠。现在改为有序列表；每一步以独立的数字列和文案列排版，数字自然占位，标题与正文共享同一左边缘。删除旧绝对定位规则。小于 900px 时转为单列，长词在需要时换行，不限制内容高度。
