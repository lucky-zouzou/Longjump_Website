# 本地部署

在项目根目录双击 `启动本地网站.command`。终端会构建网站并保持服务运行；按 Control+C 停止。依赖已在当前电脑安装，运行需要 Node.js 24 和 pnpm。

- 网站：http://localhost:3188/
- 后台：http://localhost:3188/manage/
- 账号：`local-admin@example.test`
- 初始密码：项目内 `secrets/local-admin-password.txt`，首次启动随机生成。
- 数据库及上传素材：`data/local/`，重新启动保留。

密码、数据库和素材目录已被 Git 忽略，不会随代码上传。此本地实例使用独立数据，不导入之前的 QA 测试询盘，也不连接线上客户数据库。更改密码后，初始密码文件不会自动更新。

默认只监听当前电脑的 127.0.0.1；手机无法通过上述 localhost 链接访问这台电脑。手机跨设备使用及安装 PWA 需另行配置可信 HTTPS 地址。未配置 AI 密钥时，客户仍可使用人工联络入口。

代码没有变化时可在项目目录运行 `bash 启动本地网站.command --skip-build` 快速启动。不要同时启动多个本地实例。电脑重启或服务进程退出后，重新运行启动脚本即可；当前不设置开机自动运行。
